# Seized digital assets, held to the standard of a courtroom.

A secure platform to seize, hold and track digital assets, built to meet the evidence rules of Canadian criminal law.

01 / THE CHALLENGE

When an agency seizes cryptocurrency, every key, transfer and record has to hold up in court. No single person or server can be able to move the assets, and every action has to be provable later.

02 / WHAT WE BUILT

- B001 Split-key custody Multi-party computation splits every key, so no single point of failure can expose or move the assets.

- B002 A tamper-proof audit trail Every action is written to a Hyperledger Fabric ledger, so the chain of custody cannot be changed after the fact.

- B003 One SDK for every chain A chain-agnostic SDK that works with the top 20 cryptocurrencies.

- B004 Seizure in the field A native Android app that officers use to seize assets on site.

03 / THE RESULT

Phase 1 is delivered. The agency has a custody system where every action is traceable and no one person holds the keys.
